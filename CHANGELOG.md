# Changelog

## 1.2.0 - 5 June 2026

- Rebranded the app experience to MemoLens with updated app icon, splash art, privacy copy, and Play Store docs.
- Redesigned onboarding, memories home, Create Memory, memory cards, empty states, details, and settings copy.
- Added mood support to saved memories and search/filter behavior while preserving existing saved items.
- Removed unexpected photo/camera crop prompts so selected images keep their original framing.
- Improved Google sign-out by revoking cached native access before the next sign-in attempt.
- Updated Android release metadata for the next Play internal testing build.

## 1.1.0 - 24 April 2026

- Fixed Android image sharing so supported apps receive the saved image file.
- Added favorites and tags to saved gallery items.
- Added quick filters for all items, favorites, camera, library, and top tags.
- Expanded the detail screen to edit tags and favorite state.
- Added a Settings screen with sign out, theme toggle, local data clear, and release details.
- Added an in-app privacy policy screen and support for an optional hosted privacy policy URL.
- Updated release and store documentation for the new product scope.
